# ============================================================================
# 首页展示什么：三类规则，都写在 featured.txt 里
#
# 这个文件只是**模板**（进仓库的是它，不是你的真实配置）。上手一步：
#     Copy-Item featured.example.txt featured.txt      （macOS/Linux: cp 同名两遍）
# 然后改 featured.txt —— 它已经被 .gitignore 排掉了，里面写多少真实文件名、
# 家人名字都不会跟着仓库跑到公网去。
#
# ①  一行一条【精选照片】：写完整相对路径，或者写路径里的一段关键字（不分大小写）。
#     每条规则只取第一个命中的【照片】——视频不上首页拼贴，同一张也不会重复上榜。
#     首屏那三格「会动的照片」就是按这里的行序均分的：前 3 张归左上那一大格，
#     接着 3 张归右上，再 3 张归右下。所以想要的排前面就能控制顺序。
#     写不满 9 张时，系统会用最新的照片补齐，首页不会开天窗。
#
# ②  @开头的一行是【置顶相册】（@后面写相册名，也就是一级文件夹名）。
#     它只管顺序：这本相册会被顶到「相册」页第一格（横幅位）和首页相册区最前面。
#     名字打错了、或者那本相册不存在，就当没写，不会报错也不会少一张。
#
# ③  @相册名=一段路径 是【指定相册封面】：等号后面写什么，都只在【这本相册自己的
#     照片】里找，取排在最前面那张。写完整路径最准，写个子文件夹名或文件名的一小段
#     也行（不写具体哪张）：
#         @全家福=全家福/2020婚礼/IMG_0001.jpg    ← 就用这张
#         @宝宝=百天                              ← 「百天」相关的照片里排最前那张
#     这一行顺带也把相册置顶了（不用再写一行 @全家福）；命不中就退回自动挑的
#     （相册里最新那张），不报错。只能挑照片：视频的「封面」是带播放键的占位图。
#
# 这个文件不存在、或者一条都没命中时，首页自动按「张数多的相册」一本给一格。
#
# 改完怎么生效：点页面右上角的刷新按钮（它会顺带重读这个文件），或者重启服务。
# 想加内容：把某张照片的路径粘到下面即可。在相册页点开一张照片，
# 底部信息栏显示的就是「文件夹 · 日期」，照着文件夹名写规则最好认。
# ============================================================================

# —— 下面全是照抄格式的示例，换成你自己的路径就能用 ——
@全家福
全家福/2020婚礼/IMG_0001.jpg

# 只置顶、并指定它用哪张当封面（等号那一段只在这本相册的照片里找）
@宝宝=宝宝/IMG_0102.jpg

# 路径写不全也没关系，给一段能认出来的关键字就行（取命中的第一张）
宝宝/百天
旅行/海边
