# 使用说明（可以直接发给家里人）

这是咱家自己的相册网站，照片都存在书房那台电脑里，不放在任何服务器上，
也不会传到外面去。手机、平板、电脑，只要连同一个 WiFi 就能看。

---

## 一、打开它

在浏览器地址栏里输入电脑屏幕上显示的那个地址，一般是：

```
http://192.168.1.xx:8123
```

不知道具体数字？看那台电脑的桌面，相册服务启动时会把地址打印出来；
或者直接问一句「今天的地址是多少」。**建议收藏到浏览器书签**，以后点一下就开。

### 装成手机 App（更好用）

- **iPhone**：用 Safari 打开 → 底部中间的「分享」→ 往下找「添加到主屏幕」→ 完成
- **安卓 / 鸿蒙**：用 Chrome 打开 → 右上角菜单 → 「安装应用」或「添加到主屏幕」

装好后桌面会有一个「我们的家」图标（一个屋顶加一张相框），点它直接全屏打开，
没有地址栏，跟真的 App 一样。

## 二、五个页面

顶上那一排就是导航：

| 名字 | 干什么用 |
| --- | --- |
| **家** | 首页。挑出来的照片拼成一面墙，往下滑是「最新的日子」（自己慢慢跑的横条）、几本相册，最底下是「按月翻」 |
| **相册** | 一本一本的相册，就是电脑里的文件夹。点进去还能再点子文件夹 |
| **时间** | 按时间倒着排，最近拍的在最上面。右边有年份栏，点一下直接挑；手机上是一条能横滑的年份条，会贴在顶上不动 |
| **影像** | 只有视频。点开就能播，不用下载 |
| **关于** | 这个站是怎么做的、照片存在哪、用了哪些技术 |

### 看大图

点任何一张照片就放大。

- 电脑上：键盘 `←` `→` 换上一张下一张，`Esc` 关掉
- 手机上：**往左滑看下一张，往右滑看上一张，往下拉就是关掉**
- 底部那一排小图是前后几张，点哪张看哪张
- 想看没压缩的原图，点右下角那个「新窗口打开」的图标

### 视频做成动图

在「影像」页或灯箱里打开一段视频，如果它支持，右下角会出现一个**「动图」**按钮。
点一下，会把这段视频的前几秒抽成一张循环播放的小动图——发到家庭群里特别方便，
不用传几百 MB 的视频文件。再点一次「看原片」就回到正常播放。

第一次做某段视频的动图会转十几秒（要现场抽帧），之后就快了，做好的动图会存下来。

### 搜索

点右上角的放大镜，或者在页面上直接按键盘 `/`。

- 能搜**文件名**和**文件夹名**，比如 `婚纱照`、`IMG_2022`、`小宝`
- 输入四位数字会被当成**年份**，给你一条跳到那一年的入口
- 搜索范围就是电脑里那个目录，搜不到说明文件不在里面

### 刚拷了新照片，怎么让它出现

点右上角那个**圆形箭头**按钮。它会重新看一遍目录，十几秒后刷新页面就有了。
不用重启任何东西，也不会动到原来的照片。

（就算不点，网站每 10 分钟也会自己看一眼目录。）

## 三、几个常见问题

**问：手机打开是空白的 / 连不上？**
答：先确认手机和电脑连的是**同一个 WiFi**（不是手机的移动数据）。然后确认那台电脑
开着、没睡眠。还不行就叫人在电脑上打开 `http://localhost:8123` 看看有没有画面。

**问：照片会不会被弄丢、被改？**
答：不会。这个网站对照片目录**只读不写**，它没有删改的能力。你照样可以在电脑里
正常整理文件夹，网站下一次扫描就会跟着变。

**问：视频封面是灰的、点不动？**
答：那是这台电脑上的视频处理组件没就绪。请人在项目目录里执行一次 `npm install`
然后重启服务。

**问：出去旅游想看家里的照片怎么办？**
答：目前只能在**家里 WiFi** 下看，这是有意为之——没有登录密码的网站不能放到公网上。
真需要外网访问，得另外加认证和 https，请单独提。

**问：为什么有的照片日期不对？**
答：日期是这么来的，一层一层往下找：先看**文件名**里的日期（比如
`IMG_20220315_193020`）；再看文件名里那串 13 位数字（`微信图片_20200607…`
`mmexport1602316522535` 这种带毫秒时间戳的）；都没有就看**所在文件夹名**里写的
日期；还是找不到，才用文件的「修改时间」。照片被手机助手批量拷贝过，
修改时间常常会被统一改写，这种情况日期就会挤在同一天。要修的话，改文件名
或者挑到名字里带日期的文件夹里，再点重新扫描。

**问：想让首页固定展示某几张怎么办？**
答：项目根目录有个 `featured.txt`，一行写一张（写完整路径或者写路径里的一段
关键字都行），**行序就是首页那三格照片的顺序**，前三张归左上那一大格。写完点一下
刷新按钮就生效。另外加一行 `@婚纱照` 这种（@ + 相册名）可以把整本相册顶到最前面。
不会改就叫人帮忙。

**问：不想自己动手，只想让某本相册在首页排前面？**
答：同一个文件，加一行 `@相册名`（相册名就是一级文件夹的名字）。它只管顺序，
不会凭空多出一本相册；名字写错了就当没写，不会报错也不会少照片。

## 四、给帮忙照看这台电脑的人

- 后台启动、开机自启、看日志、备份：都封装在 `scripts/gallery.ps1` 里，
  命令是 `pwsh scripts/gallery.ps1 status`，它会告诉你现在是什么状态
- 详细一点请看 [运维手册](operations.md)
